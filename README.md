---

## 📦 Installation

```bash
pip install pdfjin-compress
```

Or install from source:

```bash
git clone https://github.com/pdfjin/pdfjin-compress.git
cd pdfjin-compress
pip install .
```

---

## 🚀 Quickstart

Run via CLI:
```bash
pdfjin-compress --help
```

Use in Python:
```python
import pdfjin_compress
```
